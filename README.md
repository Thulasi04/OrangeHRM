# Playwright Python Pytest OrangeHRM Automation Framework

This project is a Python-based UI automation framework built with **Playwright and pytest** for testing the **OrangeHRM application**. It follows a **Page Object Model (POM)** approach to organize page actions, locators, helper functions, and test cases.

The framework is designed to validate OrangeHRM user flows, page navigation, UI elements, and common end-to-end user actions in a realistic web application environment.

## Tech Stack

- Python
- Playwright
- pytest
- Page Object Model (POM)
- OrangeHRM Demo App
